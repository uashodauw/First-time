小悟空陪你聊 · 公开版

· 只有一个文件 index.html，放到任何 https 静态网站（例如 GitHub Pages）即可使用。
· 不内置任何 API Key：每位访客第一次打开时，粘贴自己的 DeepSeek API Key
  （https://platform.deepseek.com/api_keys）。Key 只保存在访客自己的浏览器里，只发送给 api.deepseek.com。
· 声音使用访客设备自带的中文（普通话）声音；可以在“设置”里换声音、调音调/语速，或点“活泼小男孩”等快捷预设。
· 推荐：苹果设备用 Safari；安卓/电脑用 Chrome 或 Edge。语音识别不可用时可以点“打字”聊天。
· 必须用 https 打开（GitHub Pages 默认就是 https），否则浏览器不允许使用麦克风。

GitHub Pages 发布方法：新建一个公开仓库 → Add file → Upload files 上传 index.html →
Settings → Pages → Branch 选 main、文件夹选 /(root) → 保存，稍等一两分钟即可访问
https://<你的用户名>.github.io/<仓库名>/
