先给悟空一张“通行证”

悟空的大脑用的是 DeepSeek。请粘贴你自己的 DeepSeek API Key，就可以和悟空语音聊天啦！

  1. 打开 platform.deepseek.com/api_keys 注册并登录
  2. 点“创建 API Key”，复制那一串 sk- 开头的字符
  3. 粘贴到上面，点“保存并开始聊天”

🔒 Key 只保存在你这台设备的浏览器里，只会发送给 api.deepseek.com，不会上传到别处。聊天费用由你的 DeepSeek 账户支付。随时可以在“设置”里更换或清除。

浏览器规定要先点一下，悟空才能出声；点完后悟空会打招呼，然后打开麦克风听你说话
苹果设备推荐用 Safari，安卓/电脑推荐用 Chrome 或 Edge；iPhone 请关掉静音开关并调大音量
